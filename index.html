Sering Ditanyakan

Pengerjaan normal memakan waktu 4-7 hari kerja tergantung antrean dan tingkat kerumitan desain. Kami tidak melayani sistem urgent demi menjaga kualitas.

Anda akan mendapatkan paket lengkap berupa file master (PSD/CDR), file gambar kualitas tinggi (JPEG/PNG), dan file siap cetak (PDF).

Ya, Kami memberikan jatah revisi maksimal 3 kali untuk perubahan minor (warna, teks, dan tata letak). Jika melebihi dari batas jumlah yang ditentukan maka akan dikenakan biaya tambahan.

Sistem pembayaran menggunakan Down Payment (DP) 50% di awal sebelum projek dikerjakan, dan pelunasan 50% sisanya setelah desain disetujui. (Desain dibawah harga 30.000 tidak perlu DP)
